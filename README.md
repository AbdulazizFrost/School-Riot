# Сайт School Riot

Сайт игры в стиле её лобби:
- скачивание игры;
- аккаунты;
- живой чат;
- отчёты о багах с фото и видео;
- оценки и отзывы;
- ссылки на YouTube и Instagram;
- панель администрации.

Это один процесс на **Node.js 22.13+** (проверено на 24.15) **без сторонних библиотек**. Ставить ничего не нужно, `npm install` тоже.

## Запуск на своём компьютере

```
cd Website
npm start
```

Сайт откроется на http://localhost:8080. При первом запуске появится папка `data/`. В ней база (`site.db`), загруженные файлы (`uploads/`) и секретный ключ (`secret.key`).

## Первый администратор

1. Зарегистрируйся на сайте обычным аккаунтом.
2. Выполни в консоли сервера:

```
npm run admin -- make-admin ТвойНик
```

Другие команды:
- `reset-password <ник>` — временный пароль, если игрок забыл свой: передай его лично, игрок сменит его в аккаунте;
- `remove-admin <ник>` — снять права администратора;
- `unlock <ник>` — снять блокировку после неверных паролей;
- `list` — список администраторов.

Через сам сайт сделать администратора нельзя, это сделано специально.

## Настройки: `site.config.json`

| Поле | Что это |
|---|---|
| `youtube.channel` | Ссылка на канал, например `https://www.youtube.com/@канал`. Пусто — кнопки нет. |
| `youtube.trailerId` | ID ролика с трейлером (часть ссылки после `watch?v=`). Пусто — играет свой `public/video/trailer.mp4`. |
| `instagram` | Ссылка на профиль `https://www.instagram.com/...` |
| `game.version`, `game.requirements` | Версия игры и системные требования на странице «Скачать». |
| `limits` | Размер фото и видео в отчётах, файлов на отчёт, мегабайт в сутки на игрока. |
| `publicUrl` | Адрес сайта в интернете, например `https://schoolriot.ru`. Нужен для защищённых cookie и проверки, откуда пришёл запрос. |
| `trustProxy` | `true`, если сайт стоит за nginx, Cloudflare или прокси хостинга. |

Сервер принимает только ссылки на youtube.com и instagram.com по https.

## Выложить новую версию игры

1. Собери игру в Unity: `Builds/Windows`.
2. Поставь новую версию в `site.config.json` (`game.version`) и в `downloads/manifest.json`.
3. Упакуй сборку:

```
powershell -ExecutionPolicy Bypass -File Website\scripts\pack-game.ps1
```

Получится `downloads/SchoolRiot_<версия>_Windows.zip`. Служебная папка `..._DoNotShip` в архив не попадает. Размер и SHA-256 сайт посчитает сам, перезапуск не нужен.

## Проверка

```
npm test
```

Тест запускается при работающем сайте. Он создаёт два временных аккаунта и проверяет:
- регистрацию и защиту от ботов;
- запросы с чужих сайтов;
- чат;
- что один игрок не видит и не меняет чужое;
- проверку файлов по содержимому;
- лимиты и блокировку подбора пароля;
- заголовки безопасности.

В конце тест удаляет свои аккаунты.

## Как выложить в интернет

Нужен **VPS** (арендованный сервер) на **Ubuntu 22.04 или 24.04**:
- 2 ядра, 2 ГБ памяти (4 ГБ, если на нём же будет сервер игры), от 40 ГБ диска;
- расположен ближе к игрокам.

Обычный «статический» хостинг (GitHub Pages и подобные) **не подойдёт**: аккаунтам и чату нужен работающий сервер.

Для HTTPS нужен **домен**:
- бесплатный поддомен вроде `schoolriot.duckdns.org` (сервис DuckDNS);
- или купленный (`.uz`, `.com`…).

Без HTTPS пароли идут по сети открытым текстом: так можно только посмотреть сайт, но не пускать игроков.

Всё для установки лежит в `deploy/`:

| Файл | Что делает |
|---|---|
| `deploy.ps1` | С этого компьютера: упаковывает сайт, загружает на сервер по SSH и запускает установку или обновление. |
| `setup.sh` | Первая установка на сервере (подробности ниже). |
| `update.sh` | Новая версия сайта. Делает копию базы, заменяет файлы программы, перезапускает. База, загрузки и архив игры не трогаются. |
| `backup.sh` | Ежедневная копия базы и загрузок в `/var/backups/school-riot`, 14 дней. |
| `school-riot.service` | Служба сайта. Пишет только в свою папку данных, остальная система ей недоступна. |
| `nginx-site.conf` | nginx перед сайтом: живой чат без задержек, загрузка видео до 110 МБ, скачивание игры без копий на диске, ограничение частоты запросов. |

Что делает `setup.sh`:
- ставит Node.js 24 (из подписанного репозитория NodeSource) и nginx;
- включает файрвол: открыты только SSH, HTTP и HTTPS;
- создаёт отдельного системного пользователя для сайта;
- запускает сайт как службу;
- получает HTTPS-сертификат Let's Encrypt: перед этим спросит согласие с их условиями;
- включает автоматические обновления безопасности;
- настраивает ежедневную резервную копию.

Пересоздавать сервер, чтобы запустить его ещё раз, не нужно: повторный запуск обновит то, что уже стоит.

### Порядок

1. Купи VPS с Ubuntu 24.04. При заказе вставь в поле «SSH-ключ» содержимое файла `%USERPROFILE%\.ssh\schoolriot_ed25519.pub`. Тогда пароль от сервера не понадобится.
2. Если есть домен, направь его на IP сервера: A-запись в панели домена или IP в DuckDNS.
3. Первая установка (с архивом игры):

```
powershell -ExecutionPolicy Bypass -File Website\deploy\deploy.ps1 -Server <IP> -Setup -Domain <домен> -Email <почта> -Game
```

4. Зарегистрируйся на сайте и сделай себя администратором на сервере:

```
ssh -i ~/.ssh/schoolriot_ed25519 root@<IP> school-riot-admin make-admin <ник>
```

5. Обновления сайта потом:

```
powershell -ExecutionPolicy Bypass -File Website\deploy\deploy.ps1 -Server <IP>
```

Чтобы выложить новую версию игры: `pack-game.ps1`, затем тот же скрипт с `-Game`.

Твой локальный аккаунт на сервер не переносится: база в `data/` никуда не загружается. На сервере база своя, начинается пустой.

Резервные копии лежат на том же сервере. Время от времени скачивай `/var/backups/school-riot` к себе.

## Что сделано для защиты

- **Пароли.** Хранятся только в виде хеша scrypt с солью. Сам пароль не знает никто, в том числе администрация.
- **Сессии.** Случайный токен в cookie `HttpOnly` и `SameSite=Lax` (`Secure` на https). В базе лежит только его SHA-256.
- **Подбор пароля.** После 8 неверных паролей подряд аккаунт ждёт 15 минут. Ответ «неверный ник или пароль» одинаковый, есть аккаунт или нет, и по времени это тоже не различить.
- **Лимиты.** Ограничены частота регистрации, входа, сообщений, отчётов и загрузок.
- **Защита от ботов при регистрации** без капчи: скрытое поле-ловушка и подписанный токен формы. Если форму отправили быстрее 3 секунд, это бот.
- **Запросы с чужих сайтов (CSRF).** Отклоняются: каждый изменяющий запрос должен нести свой заголовок, и проверяется `Origin`.
- **XSS.** Всё, что пишут люди, выводится только как текст. Действует строгая Content Security Policy: скрипты только с самого сайта, без встроенных скриптов и стилей.
- **Файлы.**
  - Тип проверяется по содержимому (первым байтам), а не по имени: программа или страница, переименованная в `.mp4` или `.png`, отклоняется.
  - Хранятся под случайными именами вне папки сайта.
  - Отдаются только автору отчёта и администрации, с ограничивающими заголовками.
- **Прочее.** SQL только через подготовленные запросы. Защита от выхода за пределы папок. Запрет встраивать сайт в чужие страницы. HSTS на https. Ограничения на размер запросов и время их приёма.

## Чего пока нет (честно)

- **Подтверждения почты и восстановления пароля по почте.** Почту сайт не спрашивает. Забытый пароль сбрасывает администрация: `npm run admin -- reset-password <ник>`. Для этого нужен почтовый сервис.
- **Автоматического фильтра мата в чате.** Нарушения модерирует администрация: удаление сообщений, блокировки.
- **Проверки загруженных видео антивирусом.** Файлы проверяются только по формату. Скачивать их могут лишь администрация и автор.
- **Двухфакторного входа для администрации.**

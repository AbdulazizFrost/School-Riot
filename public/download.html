Как начать

Три шага

  1. Скачай архив кнопкой выше.
  2. Распакуй его в любую папку (правой кнопкой → «Извлечь всё»).
  3. Запусти SchoolRiot.exe. Если Windows покажет «Система Windows защитила ваш компьютер» — нажми «Подробнее» → «Выполнить в любом случае»: так Windows встречает новые программы без цифровой подписи.

Проверить, что файл скачался целиком и без подмены, можно по контрольной сумме SHA-256: в PowerShell — Get-FileHash и имя архива.
